# Типографика Last Beacon

Художественная тема — портовая маркировка ночью: плотные янтарные заголовки с тёплой тенью, молочные технические подписи на тёмных табло, бирюзовые активные элементы.

- **Jersey 20 Regular** — крупные заголовки меню, паузы и результатов. Плотные квадратные формы напоминают маркировку оборудования и сочетаются с пиксельной графикой. Растеризация 24 px на логическом холсте, целое увеличение 2× на приставке.
- **Pixelify Sans SemiBold, 600** — HUD, счётчики, цели и кнопки. Растеризация 14 px, высота прописных 10 логических / 20 физических пикселей. Это отдельный размер для чтения на четырёхдюймовом экране.

Оба семейства загружены из официального [Google Fonts](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl), commit `47d54ca1ebb14fd864695f1d39dc734f39017c33`:

- [Jersey 20](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/jersey20): `Jersey20-Regular.ttf`, `Jersey20-OFL.txt`.
- [Pixelify Sans](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/pixelifysans): оригинальный variable TTF сохранён как `PixelifySans.ttf`, лицензия `PixelifySans-OFL.txt`.

Оригинальные TTF не изменены. Лицензии SIL Open Font License 1.1 включаются и в исходники, и в пакет для приставки. Прежний черновой Harbor сохранён отдельно в `legacy/` под CC0 и больше не используется в игре.

## Воспроизведение

```sh
python3 -m venv build/font-tools
build/font-tools/bin/pip install -r tools/font-requirements.txt
build/font-tools/bin/python tools/bake_fonts.py
make screenshots
```

Генератор использует Pillow 12.3.0, выводит 190 ASCII-глифов двух начертаний. Результаты: `beacon-atlas.png`, `atlas.json` с SHA-256 источников, параметрами и версией FreeType, а также `src/font_data.hpp` с упакованным атласом. Во время игры не нужны Pillow, TTF-движок или отдельные файлы атласа.

Бинарная альфа и целый масштаб сохраняют пиксельную форму букв. Центрирование использует реальные ширины глифов. Проверяем меню, HUD, паузу и результаты в 640 × 480; снимки физического экрана — в docs/hardware. Русский интерфейс пока не включён: перед локализацией нужно отдельно проверить все кириллические глифы и обработку UTF-8.

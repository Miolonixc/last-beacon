# Last Beacon

Типографика — часть художественного направления игры. Сохранять художественную пару Stardos Stencil / VT323, читаемость HUD и чисел на физическом экране 640 × 480. Все исходники шрифтов, лицензии и способ воспроизведения атласов держать в проекте. При добавлении кириллицы проверять фактическое покрытие глифов и корректно обрабатывать UTF-8, не подменять шрифт случайным системным.

Игра ориентирована на RG40XX H / muOS. Использовать системную динамическую SDL2 с Mali; dummy/offscreen разрешены только для явных снимков. Не менять системные библиотеки, громкость, настройки прошивки и сохранения других игр.

Проверки: make all test screenshots; make muos. Аппаратные тесты tools/device-session.sh запускать явно, только после завершения другой игры. Публиковать только исходники Last Beacon и собственные игровые ресурсы. Пароли и ключи не хранить.
